# Development Guide

## Prerequisites
- **Node.js** (v18 or later) and **npm** (or bun) installed.
- **Git** with credential manager configured for GitHub.
- **GitHub CLI** (`gh`) logged in (`gh auth login --web`).
- **Supabase** account (for local development) – copy the values from your `.env.example` into a local `.env` file.

## Setup
```bash
# Clone the repository (if not already)
git clone https://github.com/superbruningod9-tech/alliarcrm.git
cd alliarcrm

# Install dependencies (using npm or bun)
npm install   # or: bun install

# Create a .env file based on the example
cp .env.example .env
# Edit .env and fill in real values for your dev environment
```

## Running the App
```bash
# Development server (Vite)
npm run dev      # or: bun run dev
```
Visit `http://localhost:5173` (or the port shown in the console).

## Testing
```bash
npm test            # runs Vitest unit tests
npm run test:related # runs integration tests that hit Supabase (ensure .env is configured)
```

## Building for Production
```bash
npm run build       # creates optimized assets in the /dist folder
```

## Linting & Type‑checking
```bash
npm run check       # runs lint, format and type checks
npm run check:lint  # ESLint only
npm run check:types # TypeScript compiler check
npm run check:build # Build verification (same as `npm run build`)
```

## Adding New Scripts
All scripts are defined in `package.json`. To add a new script:
```bash
npm pkg set scripts.<name>="<command>"
```

## Security Checks
- Ensure no secrets are committed; run `git grep -i "PAT"` or similar.
- Verify `.env` is listed in `.gitignore`.

## Publishing
The repository is already public. To push new changes after a clean history:
```bash
git add .
git commit -m "Your message"
git push --force-with-lease origin main
```
